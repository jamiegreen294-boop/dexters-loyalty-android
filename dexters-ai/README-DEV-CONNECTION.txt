Dexter’s AI development connection notes

This branch is development-only. The live Dexter’s applications are not changed by this project.

The Command Centre uses the new Dexters AI Supabase project and its Edge Function. Privileged credentials remain server-side.

For the first browser test, the development Command Centre may request the Supabase publishable key. Publishable keys are intended for public client applications; never enter a secret/service-role key.
